# 美股监控看板

每日自动生成的美股监控看板 · 数据来自公开市场行情（yfinance）

**👉 [查看最新看板](https://bitbabylee.github.io/us-monitor/)** ·
[使用手册](https://bitbabylee.github.io/us-monitor/manual.html) ·
[历史归档](https://bitbabylee.github.io/us-monitor/history.html)

## 更新时间

| 版本 | 美东时间 | 北京时间 |
|---|---|---|
| 盘前版（当日计划） | 08:30 | 20:30 |
| 收盘版（当日复盘） | 16:30 | 次日 04:30 |

工作日自动运行，也可在 Actions 页手动触发。

## 结构

看板分三层，对应决策的三个问题：

1. **今天做什么** — 大盘环境 → CAMSLIM 仓位上限 → 聚焦清单 → 日内时机
2. **为什么** — 盘前雷达、双指数阶段、宏观确认层、信号预警卡、财报雷达
3. **环境背景** — 板块榜、主题榜、观察池全表、AI 资本周期

## 模块

| 模块 | 内容 |
|---|---|
| m1 | 大盘量化诊断（MA50 偏离 / RSI / VIX / MTUM÷MAGS 因子轮动） |
| m2 | 板块 ETF 微观异动（超额 Alpha + 量倍 + 放量砸盘检测） |
| m3 | 自定义主题池动能榜 |
| m4 | 观察池日线五大买点形态 + CMF/MFI 资金流 |
| m5 | 日内 VWAP / ORB 择时（8 档信号 + 跳空闸门） |
| m7 | 双指数阶段模型（QQQ + SMH 两道关卡） |
| m8 | 信号预警卡（数值每日重算 + 状态机去重） |
| m9 | 盘前/盘后雷达 |
| m10 | CAMSLIM 派发日体系（欧奈尔/IBD） |
| m11 | 筛选器（RVOL / Compression / Gappers） |
| m12 | AI 资本周期看门狗（capexcycle.com 季度数据） |
| m19 | 全量 ETF 涨幅榜（5/21/63日涨幅 + 持续性；AUM≥$3亿与21日均成交额作交易准入，完整列表仍保留并可筛选） |

阈值集中在 `us_monitor/config.py`。
