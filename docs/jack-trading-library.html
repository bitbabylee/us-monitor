一、先把三层内容分开

可以共用

候选品种预筛

市场环境、赛道/行业强度、个股相对强度、流动性、波动性、是否靠近高位、是否先涨后整理。这些用于回答“值得不值得继续看”。

按策略独立

入场触发

突破枢轴、突破箱顶、回撤反转、财报缺口后的 ORH、窄幅日后的开盘突破，是不同策略。预筛不能把它们合并成一个买点。

按交易独立

风险与退出

止损应落在该策略的失效点：结构低点、箱底、开盘区间低点或均线失守。不能只套固定百分比，也不能事后移动得更宽。

外部质量层

基本面与 Buffett 过滤

生意质量、资产负债表、估值与管理层可用于限制研究范围，但不是 Jack 技术策略的入场条件，也不能替代止损。

最容易混错的地方：VCP、旗形、杯柄、箱体可能共享“供给减少、价格收紧”的底层现象，但形态定义、基座长度、枢轴位置和失败判定仍然不同；EP 与普通突破更不能混为一谈。

二、Jack 视频反复使用的共同框架

Identify · 识别市场、赛道、领导股、结构和催化剂。先决定看什么，不急着交易。
Control · 控制入场前定义失效位置、风险金额和仓位。错误时让损失很小。
Mitigate · 缓释价格按预期运行后，减仓、推止损或让部分仓位“免费持有”。
Optimize · 优化记录胜率、平均盈亏与行情反馈；表现差时降低暴露，表现好时渐进增加。

这个四步框架可以共用；但每个视频在 “Identify” 和 “Control” 里用的具体条件不同，下面逐一保留。

六、家族 D：Qullamaggie Episodic Pivot（EP）

事件驱动 · 单独模块

EP 不是“普通 VCP 加一个缺口”。它要求事件/信息冲击、异常成交量和开盘后的价格接受；通常需要盘中执行。

环境/形态盈利/销售或重大催化带来向上缺口，成交量显著高于常态，价格越过基座和关键均线。
触发常用首个 5 分钟 K 的高点（ORH）作为触发；等待开盘区间完成，而不是开盘直接追。

必须人工新闻质量、缺口是否已过度、盘前流动性与开盘成交。
低盯盘适配：低。需要开盘后观察和下单，不应作为你的第一阶段主策略。
Qullamaggie Breakout Setups — Flags & Episodic Pivots把延续旗形与 EP 放在同一视频比较，但仍是两个 setup

环境/形态旗形来自已有趋势后的收紧；EP 来自新信息冲击后价格/成交量的状态跃迁。

七、家族 E：Charles Harris 强势股回撤

不是突破策略

环境/形态偏好牛市与领导股；价格回到 10/20/50 日线、前突破位或明确支撑，而非接下跌刀。

风险/退出回撤低点/支撑下方；若价格继续形成更低低点，交易假设失效。

低盯盘适配：中。可做日线收盘策略，但它需要一套独立于突破的触发和统计记录。

可以进入同一个候选池

  • 强市场与强行业
  • 流动性、ADR、52周位置
  • RS、均线趋势、先涨后整理
  • ATR/成交量收缩
  • 距离枢轴与结构止损

不能合成一个“买入信号”

  • VCP 枢轴 = EP 开盘区间高点
  • 箱顶突破 = 回撤反转
  • NR7/ORB = 日线趋势突破
  • 高 ADR = 买点
  • 好基本面 = 可以忽略价格风险
